# 🏀 Level Up — Basketball Training App

**Level Up** is a mobile iOS app designed to help basketball players improve their skills through structured drills, video guidance, and progress tracking. Built with Swift and Firebase, the app is tailored for players who want to train smarter — whether at home or on the court.

📱 **Available on the App Store**  
🔗 [Download Level Up](https://apps.apple.com/us/app/together-level-up/id6463521780)

---

## 🚀 Features

- 🎯 **Skill-based Drills**  
  Choose from curated basketball workouts targeting shooting, footwork, agility, and more.

- 📹 **Video Guidance**  
  Watch clear video demonstrations for each drill with pro-style breakdowns.

- 📈 **Progress Tracking**  
  Log completed workouts, track performance over time, and build consistency.

- ☁️ **Firebase Integration**  
  Secure login, real-time data sync, and cloud video storage using Firebase.

- 👥 **Community Ready (coming soon)**  
  Add friends, share progress, and challenge teammates.

---

## 🛠 Built With

- `Swift` — iOS development
- `Xcode` — IDE for building and testing
- `Firebase` — Auth, Firestore, Storage
- `UIKit` — Interface design
